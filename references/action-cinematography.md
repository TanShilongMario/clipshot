# 动作摄影与非常规构图

用于打斗、追逐、跌落等动作段落，或用户要求更强的构图与摄影表现力时。普通对白戏不必加载整套动作流程。以下是创作选项，不是特殊镜头配额；选择由剧本、基调、画幅和拍摄条件决定。

## 先设计力量与观看位置

先确定观众跟谁共享身体体验、危险来自哪里、什么动作改变局势。为决定性节拍写清：

- 预判：目标、阻力、距离与攻击方向，观众比人物先知道还是后知道；
- 蓄势：支撑脚、握点、身体压缩或短暂停顿；
- 释放与接触：力从哪里传到哪里，接触点与重心怎样改变；
- 余势与代价：身体如何失衡、滑动或停止，空间与道具留下什么结果。

只选本段需要的环节，不把每次出招都拆成四镜。固定全景可以完整保留动作力量；特写用于触点、信息或反差，不能用碎切掩盖动作因果。

关键节拍在内部比较常规覆盖与表现性方案，保留摄影带来实际收益的一版，无需把内部比较全部交付给用户。为整段选定观看原则，例如“贴近逃跑者的地面高度，出口始终在远处”或“固定几何秩序被人物逐步撞破”，避免每格随机换一种炫技手法。

## 构图：把术语转成画面关系

坐标以格内左上为原点，x 向右、y 向下；比例与角度是设计目标，可近似表达，不宣称图像生成器能精确执行。倾斜方向按观众看到的画面描述。

| 语言 | 具体设计 | 检查与限制 |
|---|---|---|
| 荷兰角 / Dutch angle | 例如地平线向右下倾约 20°，人物反向撑住斜线；受力后身体顺斜线滑出 | 固定倾斜是机位状态；镜头在动作中旋转才是 ROLL。倾斜后仍留可辨的地面或建筑锚点，不让人物凭空失重 |
| 黄金分割 | 将决定性接触点放在约 x=0.618、y=0.382；前景手臂和后景出口引导视线到该点 | 这是可选位置关系，不是高级感保证；不与三分法混称。可先建立平衡，再让动作把视觉重心挤出该位置 |
| 对角线与三角楔形 | 前景肢体与门框形成两条相交斜线，将目标压在狭小楔形区域；反击时撑开这一区域 | 明确斜线由什么物体构成；不能靠随意歪画背景实现 |
| 极端切边 / 局部身体 | 画框切掉头部，保留撑地手、肩背与远端追击者；接触点靠近画缘 | 裁切必须有信息取舍；关键抓握、受力关系被裁掉后应在相邻格补明，不生成缺肢或解剖错误 |
| 框内切分 | 门框、楼梯、栏杆、身体或阴影把单个空间划成不等区域；人物跨越分界改变优势 | 画面内部的遮挡结构，不是把九宫格再切成额外分镜。需要成片分屏时明确标注各子画面的时空关系 |
| 负空间与反向留白 | 人物被挤到边缘，空区先留给未知威胁；攻击进入空区后改写视觉重心 | 空白有预期或压迫作用，避免仅用人物偏置冒充设计 |
| 前景巨物与尺度差 | 近处握拳或门闩占据大面积，远处人物仍可辨认；动作沿纵深逼近镜头 | 用透视与轮廓表达，不依赖景深虚化；检查道具比例及人物空间位置 |
| 俯视几何与贴地仰视 | 俯视展示追逐路线交叉；贴地让脚步、滑行与障碍占据前景 | 角度改变必须获得路径、重量或威胁信息；避免把同一动作任意换角度当作推进 |

每格选择主导关系，避免同时强塞荷兰角、黄金分割、鱼眼、分屏和极端切边。漂亮但削弱动作的构图应舍弃。

## 运镜：定义轨迹，而非只命名

每个复杂运动写成：**起始构图 → 动作触发 → 摄影路径与速度变化 → 结束构图 → 持续或切点**。说明摄影与人物同步、滞后还是反向；运动速度是相对关系，没有依据时不编造设备参数。

| 选择 | 可执行描述 | 必须解决的问题 |
|---|---|---|
| 贴地横向跟随 | 镜头与侧滑人物同步横移，桌腿依次穿过前景，最终停在撑地手旁 | 前景视差与人物屏幕方向一致，路径不穿实体障碍 |
| 延迟跟随 / 越过人物后揭示 | 人物先动、镜头稍后追上；或人物停下，镜头继续滑移才露出堵住出口的人 | 明确延迟揭示的是什么，不写成无动机的漂移 |
| 弧形绕拍 | 以两人的接触点为中心绕行，前景肩背逐渐让出后方出口 | 写起止方位与转向；越轴通过连续移动和稳定锚点让观众理解 |
| 反向运动 | 人物向右冲，镜头向左移，障碍高速掠过画面；落点交代双方距离 | 相对速度增强后仍要看清谁接近谁，不让背景运动冒充人物反向 |
| 遮挡后揭示 | 镜头移到柱后被遮满，再移出时露出对手已抢占出口 | 同镜连续运动与遮挡剪切分别标明，不默认遮挡就等于剪切 |
| 甩镜接动作 | 从明确起点沿攻击方向甩向落点，落稳才显示撞击结果 | 起点、方向、目标与切点齐全；分镜用扫动线和前后运镜节点表达，不渲染摄影模糊 |
| 光轴滚转 / ROLL | 画面由水平随人物失衡转成倾斜，结束时保留地面锚点 | 区分镜头旋转与角色翻滚，不默认跟随滚满 360°，不误写 TILT |
| 升降揭示 | 从人物背后低位上升，越过遮挡露出围堵路线 | 说明视线如何越过障碍、何时揭示；真实拍摄场景需说明支撑或替代方案，不凭空穿墙 |

媒介保持结构人体、墨线和马克笔块面。相机位置、焦感、透视与运动可大胆设计；抽象绘制不等于保守摄影。

## 节奏与运镜节点

节奏从蓄势和释放的差异产生：可以长停顿后突发动作，也可以连续追逐突然静止。不要默认越短、越晃、越多特写就越有力量。切在观众需要改变注意对象或获得信息的时刻。

复杂运镜用同一镜头的 a/b/c 运镜节点占相邻格，分别展示起始、转折、落点；静态单格能表达的机位不必扩成三格。这些节点属于分镜，不是成片关键帧。编号和计时遵循 [deliverable-schema.md](deliverable-schema.md)。

### 示例：走廊闪避后发现出口被堵

以下只说明设计方法，不是可迁移到每个项目的固定九镜模板。

- 起点：腰部高度固定全景，人物与出口同框，墙面矩形建立稳定秩序；脚步逼近而人物尚未移动。
- 闪避：切到贴地跟随镜头 S02a，撑地手靠近约 x=0.618 的视觉落点；前景攻击者腿部形成斜线，主角向右侧滑。
- 同镜转折 S02b：桌腿遮掉部分身体，手与支撑脚仍能说明运动方向；镜头与人物同步横移，无剪切。
- 同镜落点 S02c：人物停住，镜头继续短距离移动才露出远端堵门者；保持原轴线与出口位置，观众获得新的空间后果。
- 反应：固定偏置中景，门框把人物挤进狭窄区域，动作停止，留时间让失败的逃跑意图成立。

若这一段选择荷兰角，应把它绑定到具体的失衡节拍，并设计恢复或保留倾斜的原因，不再无差别叠加到上述每格。

## 生成前的表现力审查

- 替换：关键镜头换成普通平视中景会失去什么信息、身体感或图形关系？没有损失时重选方案；常规镜头若更准确就保留。
- 连贯：遮挡、倾斜或碎片化之后，观众靠哪个接触点、方向或环境锚点理解结果？
- 反差：节拍是否有有意安排的速度、尺度、稳定性或留白变化？不要求每项都变化。
- 可画：提示词是否给出位置、面积、裁切、姿态、起止路径？只写“顶级、炸裂、高级构图”无法指导作画。

生成后按 [visual-production.md](visual-production.md) 的 PASS 6 检查实际画面。文字方案成立不等于图像已实现；尚未生成图像时只能报告设计与文档检查结果。
