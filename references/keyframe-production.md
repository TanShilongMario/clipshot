# 成片关键帧制作

仅在分镜阶段已经完成，且用户明确同意继续制作成片关键帧后读取。这里的“成片关键帧”是表达最终人物、场景和美术方向的独立画面，不是九宫格分镜、分镜单格放大，也不是连续运镜的 a/b/c 节点。

## 不可混用的职责

| 输入 | 只决定什么 | 不得决定什么 |
|---|---|---|
| 已确认分镜 | 镜号、画幅、机位、景别、构图、主体位置、动作瞬间、屏幕方向、运镜意图、光源方向与明暗结构 | 人物长相、服装设计、场景美术细节、材质体系、最终艺术风格 |
| 用户素材与明确选择 | 人物身份与外观、服装、道具、场景、时代、材质、色彩体系、绘制或渲染风格 | 未经确认改写剧情、机位、构图、动作结果或镜头方向 |

把分镜当作摄影蓝图，把用户素材当作美术事实来源。两者冲突时不要自行折中：指出冲突项，并请用户选择保留分镜摄影设计、遵循素材设定，或授权具体调整。最终美术呈现必须充分尊重用户的选择。

## 启动条件

完成分镜图、时间线与连续性提示后，明确询问用户是否继续制作关键帧。只有得到肯定答复才继续。

生成前确认：

1. 要制作的镜号；默认不把九格全部转成关键帧，也不替用户选择“最重要”的镜头。
2. 每个镜号对应的人物、服装、道具和场景素材；素材较多时列出简短映射供用户确认。
3. 哪一份素材或哪段文字是最终 STYLE 依据。不得把写实度、媒介、年代、色彩或艺术流派留给 Agent 擅自决定。
4. 输出画幅与尺寸。默认继承该镜头已确认的单格画幅，不继承九宫格合成画布比例。
5. 允许偏离素材或分镜的范围，例如是否允许补全未展示的服装、场景区域或背面细节。

人物、场景或 STYLE 素材缺失且会产生多种合理美术答案时，先请求用户补充或明确授权 Agent 提案。可以提出选项，但必须先获选择；不得从分镜的纸张、墨线、马克笔或高亮箭头推断成片风格。

## 素材优先级与溯源

- 只使用当前任务中用户提供或明确指定的素材；不迁移示例、旧项目或 Agent 偏好的美术设定。
- 用户的文字决定素材角色：PERSON / COSTUME / PROP / LOCATION / STYLE。不要仅凭图片外观擅自把一张图升级为 STYLE。
- 同类素材冲突时，以用户明确指定的主参考为准；未指定则先询问，不做平均脸、混合场景或混合画风。
- STYLE 素材决定媒介、笔触或渲染方式、色彩体系、材质处理和完成度。人物照片不自动决定写实风格，场景照片不自动决定摄影质感。
- 分镜中的灰阶、红色动线、镜号、箭头、边框、gutter 和注释都是工作标记，不进入关键帧，除非用户明确要求保留。

## 制作流程

1. 建立关键帧 brief：镜号、叙事瞬间、锁定的摄影参数、人物/场景/道具/服装/STYLE 素材及各自用途。
2. 从分镜提取摄影骨架：画幅、机位高度与方向、景别、主体占比与位置、前中后景、遮挡、动作落点、视线、光源方向和影子关系。
3. 从用户素材提取美术事实：角色外观与比例、服装结构、道具造型、场景布局与设计、材质、色彩、媒介和艺术风格。
4. 逐项写入生成或编辑指令，并明确：`Storyboard reference controls camera, composition, blocking, motion intent, and lighting structure only. User assets control character, location, production design, and final art style.`
5. 每个目标镜头输出一张独立关键帧。除非用户明确要求联系表，不把关键帧塞回九宫格，也不保留分镜标记。
6. 检查实际图像；失败时按问题来源修正，不用改变另一类输入来掩盖错误。

## 强制检查

逐张给出 PASS / FAIL，任一 FAIL 不得交付：

### CAMERA FIDELITY

- 是否保持该镜号的画幅、机位、景别、构图、主体位置、动作瞬间、屏幕方向和光影结构？
- 静态关键帧是否用构图和动作状态表达运镜意图，而不是画入箭头或生成多个重影人物？

### ASSET FIDELITY

- 人物、服装、道具和场景是否分别遵循已确认素材？
- 是否没有从分镜结构人体臆造角色长相，也没有把参考主体替换成泛化设计？

### STYLE FIDELITY

- 媒介、色彩、材质、笔触或渲染完成度是否遵循用户指定的 STYLE 来源？
- 是否没有把分镜的墨线、纸面、马克笔灰阶和红色箭头误当成最终艺术风格？
- 是否没有混入 Agent 自选的“电影感”、流行画风或未获授权的写实化？

### CLEAN FRAME

- 是否为独立、干净的成片关键帧，没有九宫格边框、镜号、时间码、运镜箭头、长注释或 storyboard sheet 痕迹？
- 是否没有未经用户要求的水印、字幕、UI 或分屏？

## 错误恢复

- 机位或构图错误：回到分镜摄影骨架，保持素材与风格不变。
- 人物、场景或道具错误：加强对应素材映射，保持镜头设计与 STYLE 不变。
- 艺术风格错误：只回到用户指定 STYLE 来源，保持镜头与内容连续性；不要用分镜媒介兜底。
- 素材之间互相冲突：停止生成并请用户裁决，不擅自融合。

交付时按镜号列出：使用了哪些用户素材、继承了哪些分镜摄影要素，以及任何经用户授权的偏离。不得宣称仅凭分镜就确定了人物、场景或最终艺术风格。
