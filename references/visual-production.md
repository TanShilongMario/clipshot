# 九宫格与单格图像制作

仅在生成、编辑或审查实际分镜图时读取。创建或编辑位图分镜时使用当前环境可用的图像生成能力。

## 九宫格规格

- 一张合成图内严格包含 3 列 × 3 行，共九格。
- 九个画框外部尺寸、内部画幅与间距一致；不得出现跨格大画面或大小混排。
- 阅读顺序为从左到右、从上到下，镜号 01—09。
- 横屏项目每格为 16:9；竖屏项目每格为用户指定的 3:4 或 9:16。整张画布比例由九格排版自然决定，不要把单格画幅误当成合成图画幅。
- 留出清晰白色 gutter 和明确黑边框；边框在缩略图中仍可辨认。除镜号、极短运动标记外，不在图内放长句、对白或时间线。

## 固定视觉语言

以制作型故事板而非成片概念图为目标：

- 白色或暖白纸面，黑色钢笔、铅笔或墨线速写；主体轮廓果断，内部可保留快速结构线和动作弧线；
- 场景只用透视框架、空间锚点和少量概括线建立拍摄关系，不渲染全部材质；
- 以纸白、浅灰、中灰和极少深灰的大块马克笔面区分前后景与焦点，避免碎小灰点；
- 只用一种克制的红色或用户指定高亮色表示人物路径、动作弧线、视线或镜头轨迹；
- 人物不是符号小人，但也不是肖像插画：身体比例、肩线、脊柱、骨盆、关节方向、受力、重心、接触点与表演姿态必须准确；
- 面部只保留足够辨认情绪、视线和角色身份的结构笔画；服装褶皱和道具纹样只画影响动作或辨识的部分；
- 动作需要时使用少量重复轮廓、速度线、撞击线或抽象运动场；
- 保留景别变化、前中后景、环境尺度和有限主导色，不追求照片写实、精致漫画、精细成片光效、复杂金属渲染或概念海报质感；
- 禁止用密集交叉排线、重复草木、泥点、雨雾颗粒或纸张脏纹制造“完成度”。清晰度来自轮廓、块面、透视和动作，不来自细节数量。

## 生成提示词结构

按以下顺序组织提示词，并将九格逐格写清：

1. 交付物：production storyboard sheet，strict equal 3×3 grid；
2. 每格画幅、边框、gutter、编号和阅读顺序；
3. 全局媒介与有限色彩；
4. 角色与场景连续性锚点；
5. Shot 01—09 各自的景别、机位、构图、动作瞬间、视线、环境信息和箭头；
6. 明确艺术参考与连续性参考各自的作用，不继承参考图中的无关内容；
7. 全局禁项：no merged panels, no unequal frames, no extra panels, no long captions, no photorealistic finish, no polished illustration, no dense crosshatching, no decorative arrows, no inconsistent costumes or props。

不要只写氛围词或导演姓名。每格至少指定：主体位置、镜头高度/角度、景别、可见动作、环境锚点、运动方向。若使用参考图，逐张标明其角色：内容依据、连续性参考或艺术/镜头语言参考；明确要继承和排除的特征。

双方案生成时分别写两套完整提示词。除共享的剧情与连续性锚点外，各自明确观看立场、构图原则、景别节奏、运镜策略和转场逻辑；不要依赖“同一提示词换一个风格名称”获得差异。

## 高亮线规范

- 人物移动：红色实线箭头，沿地面路径或身体运动弧线。
- 镜头运动：画框边缘的红色箭头，加极短英文标签。
- 视线：细红虚线，仅在空间关系难以读懂时使用。
- 动作前后位置：必要时使用浅红轮廓或起止点，不制造多个实体人物的误读。

同一格最多突出一项主要运动，复杂动作可拆成相邻镜头。

## 生成后视觉检查

必须实际检查生成结果，而非仅相信提示词：

1. 数出恰好九格，确认无合并、缺失、重复或额外小格；
2. 检查每格画幅、边框和间距一致；
3. 逐格核对镜号与脚本节拍；
4. 核对人物发型、服装、体型、关键道具和空间方向；
5. 核对红线是否准确落在人物动作或镜头轨迹上；
6. 检查姿态重心、接触关系、透视和遮挡；
7. 检查特殊转场是否在相关两格之间形成可见关系。

若交付双方案，再并排检查两版的缩略图节奏：至少三项镜头语言维度应形成整组差异；不能只有灰阶、颜色或笔触不同。

若格数或结构错误，重新生成整张九宫格；若只有单格内容偏差，优先保持整体布局的编辑方式修正。无法保证图内文字准确时，减少文字，仅保留视觉镜号，并以外部时间线表为准。

## 单格放大

将目标格视为既有镜头的高分辨率深化，而不是重新创作：

- 锁定原画幅、机位高度、镜头方向、主体位置和动作关键帧；
- 锁定角色身份、服装、道具、环境地标、光线方向和主导色；
- 允许增加准确的手部、表情、材质、空间层次、群演行为、天气或烟尘；
- 原格若有红色动线，放大后保持相同起止方向并提高标记精度；
- 不添加后续剧情，不改变人物输赢、道具归属或动作结果。

输出时同时列出“保持不变的连续性锚点”和“本次新增细节”。
